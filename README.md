## Deploy to Vercel

This is a static HTML site — no build step required.

### One-Click Deploy

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/Bradbuythedip/trump2028)

### Manual Deploy

1. Install Vercel CLI:
   ```bash
   npm i -g vercel
   ```

2. Deploy:
   ```bash
   vercel
   ```

3. Deploy to production:
   ```bash
   vercel --prod
   ```

### Connect via Vercel Dashboard

1. Go to [vercel.com/new](https://vercel.com/new)
2. Import the `Bradbuythedip/trump2028` GitHub repository
3. Framework Preset: **Other**
4. Build settings — leave all blank (no build command, no output directory needed)
5. Click **Deploy**

Vercel will automatically serve `index.html` from the root. Every push to `main` triggers a new deployment.
